# Tabela de percentuais (referência do treinador)

Tabela usada pelo treinador para montar os tempos de treino a partir do **melhor tempo** do atleta numa distância (testes de 50, 100 ou 200 m, por exemplo).

> Guardada como referência. **Ainda não é usada pelo app.** A ideia: quando o atleta registrar testes de 50, 100 ou 200 m, o app pode usar esta tabela para os tempos de cada intensidade, no lugar da estimativa feita só pelo teste de 400 m.

A foto original está em [`referencias/tabela-de-percentuais.png`](referencias/tabela-de-percentuais.png).

## Como a tabela é calculada

Cada coluna é o melhor tempo **mais** a diferença em porcentagem:

> **tempo = melhor tempo × (1 + (100% − coluna) ÷ 100)**

Ex.: melhor tempo 1'04" (64 s) na coluna de 80% → 64 × 1,20 = 76,8 s = **1.16.8**.

| Coluna | Zona | Multiplica o melhor tempo por |
|---|---|---|
| 100% | POT. (potência) | 1,00 |
| 95% | TOL / RES (tolerância / resistência) | 1,05 |
| 90% | VO2 (AN1) / A3 | 1,10 |
| 85% | A3 / A2 | 1,15 |
| 80% | A2 / A1 | 1,20 |
| 75% | A1 / A0 | 1,25 |
| 70% | — | 1,30 |
| 65% | — | 1,35 |
| 60% | — | 1,40 |

Formato dos tempos: `m.ss.d` (minutos, segundos, décimos). Ex.: `1.07.2` = 1 minuto, 7 segundos e 2 décimos. Abaixo de 1 minuto: segundos e décimos (`29.4`).

## Observações

- As linhas coloridas na foto original (amarelo, verde, azul e laranja) são marcações do treinador e não mudam o cálculo.
- Na foto, a linha de 1.08 na coluna de 80% aparece como `1'21.6`; pelo cálculo é `1.21.6` (mesmo valor).
- Na **coluna de 95%**, a foto mostra valores até 0,2" menores que o cálculo a partir de uns 1'40" (ex.: linha 2.30: foto `2.37.3`, cálculo `2.37.5`; linha 2.00: foto `2.05.8`, cálculo `2.06.0`). As outras colunas batem exatamente. A tabela acima segue o cálculo; se a da foto for a certa, é só ajustar.
